BigTinyNum

BigTinyNum is a casual number puzzle mini game built for the TikTok platform. Players combine numbers, improve reaction speed, and challenge global leaderboard rankings.

Game Features

  • Fast and simple number puzzle gameplay
  • TikTok leaderboard support for competitive ranking
  • Rewarded advertisement features for optional in-game rewards
  • No separate registration required — users play directly with their TikTok account
